# Y-SCORCH_manuscript

This repository includes scripts for the results generated in:

---

- Folder 01-Regional_data_processing/ includes the scripts to further process the RNA data including cell type annotations and figure generating scripts to plot tSNE / marker genes

- Folder 02-ATAC_processing/ includes the scripts to further process the ATAC data

- Folder 03-DE_analysis/ includes the scripts to run DEG analysis on the RNA data

- Folder 04-ATAC_DE/ includes the scripts to run ATAC DE analysis

- Folder 05-communication/ includes the scripts to run cell-cell communication analysis

- Folder 06-/astrocyte/ includes the scripts for astrocyte analysis

- Folder 06-/Viral_Detection includes the scripts to run viral detection
